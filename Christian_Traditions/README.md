<a id="reading-method"></a>
## Reading Method | 阅读方法

Ask which kind of label is being used, who defines it, and what the source actually supports. A church family's name alone does not settle every doctrine or describe every member.<br>
先问标签属于哪一层、谁作定义，以及来源实际支持什么。一个教会家族的名称不能定下全部教义，也不能描述每位成员。
