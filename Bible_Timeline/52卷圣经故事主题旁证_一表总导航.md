## 一、先记住整条接力

**创造与破裂 → 救赎与同在 → 土地与失序 → 王与圣殿 → 智慧与苦难 → 先知与被掳 → 归回仍等候 → 耶稣成全应许 → 圣灵使福音越界 → 福音塑造教会 → 受苦中持守 → 羔羊完成新创造**

表中的主题代码分为八条主干和三条伴线：

- **A 后裔与应许；D 神的同在；C 圣约；K 国度；X 出埃及与释放；T 圣殿、祭司与祭物；N 万国；R 被逐、归回与新创造；**
- **W 智慧与义人生活；S 受苦与忠心见证；G 圣灵与新群体。**

旁证类型则是另一条轴：

- **EV** 触及人物、政权行动、战争、流亡、处决等事件坐标；
- **BG** 照明城市、制度、法律、劳动、敬拜或文学环境；
- **MS** 证明某段文本在某时某地已经流传；
- **RX** 显示后期解释、礼仪、书目或信仰接收；
- **UT** 标出器物不能直接裁定的神迹、启示、赎罪、复活与神学实现。

锚点编号的详细来源、A–D 强度和“能支持／不能支持”，须回到[205 个锚点对应表](./旁证锚点_52周与66卷对应表.md)及[史料与考古旁证索引](./史料与考古旁证索引.md)核查。古代 22／24／39 卷计数与本项目 52 卷课程的关系，另见[旧约书目桥接专题](./古代旧约书目_22卷24卷39卷与52卷路线桥接.md)。

## 二、十二段历史坐标层

### 先分清四只时钟

1. **故事时钟：** 经文把人物和事件放在哪个时代。例如《但以理书》的故事从巴比伦转到波斯。
2. **写作／编集时钟：** 书卷何时形成现有文学形态。它可能与故事时代接近，也可能经过较长传承；有争议就保留范围。
3. **幸存抄本时钟：** 目前实际发现的副本何时制作。最早幸存抄本只给“至迟已有这段文本”的下限，不等于原作年份。
4. **接收时钟：** 后来的群体何时引用、翻译、诵读、注释或编目这卷书。它能证明后期使用，不能倒作原事件的同期档案。

下表的“可固定坐标”只列代表点，不替代各专题的完整年表。十二段之间另列“第二圣殿世界”转场，因为它没有新增一卷新教旧约主读书，却是从《玛拉基书》世界走到四福音不可省略的历史桥。主前／BCE 年份数字越小越晚；主前 1 年之后直接进入主后 1 年，没有第 0 年。

### 三个读年表的校正

- **固定事件不等于整卷定年：** 主前 597 年的巴比伦编年史可固定一次攻城，却不能仅凭这一点决定《耶利米书》全卷何时完成。
- **最早副本不等于原作：** 一份主前二世纪残卷能证明当时已有该段文本，不能把作者和故事都改写成主前二世纪。
- **背景下限不等于事件日期：** 梅尔内普塔碑证明约主前 1208 年迦南已有“以色列”，不能倒算出埃及发生在哪一年。

## 四、四个不能跳过的解释关口

### 1. 智慧书不是时间线的岔路

《箴言》《传道书》《约伯记》被放在《列王纪》之间，是有意让读者停下来追问：即使有律法、王、圣殿和看似稳定的社会，人究竟怎样在日常选择、死亡限制和无解苦难中忠心？它们不新增一段国家年代，却训练能活在整条故事中的人。

### 2. 归回不是故事的圆满结局

圣殿、城墙和群体制度的恢复都是真实进展；《以斯拉记》《尼希米记》《玛拉基书》的结尾却显示人心、敬拜和公义仍会反复。因此归回必须继续等待新约、新心、圣灵、君王和神亲自同住，不能把波斯时期返乡直接等同于先知全部应许已经完成。

### 3. 书信不是福音故事之后的附录

四福音宣告耶稣是谁、做了什么；《使徒行传》和书信则检验这好消息能否形成一个跨民族、处理金钱、性、权柄、受苦、分裂与盼望的真实群体。若只读福音事件而跳过书信，故事会停在“耶稣完成救恩”，却看不见圣灵怎样把救恩塑造成教会生活。

### 4. 《启示录》不是另开一条末世密码线

最后一卷重新收回创世、出埃及、羔羊、圣殿、巴比伦、生命河和生命树。它的终点之所以重要，不只是“将来发生什么”，而是因为神与人同住、死亡消失、列国得医治，逐项回答了《创世记》以来的失落。

## 五、使用时的证据闸门

1. **看见 EV：** 先说清它具体固定了哪个人物、政权或事件坐标；不要把局部相合扩成全卷每个细节都获外证。
2. **看见 BG：** 结论写成“这使经文处境更可理解”；不要改写成“这证明故事已经发生”。
3. **看见 MS：** 结论写成“这段文本至迟在某时某地已经流传”；抄本年代不自动等于写作年代，更不等于卷内事件年代。
4. **看见 RX：** 它回答后人怎样阅读、争论、敬拜或编目；后期接收不能倒作原事件的同期档案。
5. **每卷都有 UT：** 这不是说历史不能研究，而是承认器物不能独自证明神迹、启示、赎罪、复活及预言的神学实现。
