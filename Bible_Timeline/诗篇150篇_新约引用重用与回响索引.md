> This index accompanies week 32 and offers reverse lookup for the Gospels, Acts, Pauline letters, Hebrews, and Revelation. It lists all 150 psalms using Masoretic numbering familiar in Protestant Chinese Bibles, including the Chinese Union Version. Only correspondences meeting the current threshold are included. It is reviewable and expandable, not an exhaustive count treating every similar word as fulfilled prediction.<br>
> 本表服务于 52 周计划第 32 周，也为福音书、使徒行传、保罗书信、希伯来书和启示录提供反向查经入口。它按《和合本》等新教中文圣经通行的马所拉本编号列出 150 篇；每一篇都有一行，但只把达到当前证据阈值的对应列入。它是一份可复核、可扩充的工作索引，不是把所有相似词语都计算成“预言应验”的穷尽统计。

## How to Read the Table | 一、怎样读这张表

<a id="psalms-index-1-four-markers"></a>
### 1. Four Markers | 1. 四种标记

| Marker / 标记 | Working definition / 工作定义 | Limit / 使用边界 |
| --- | --- | --- |
| **Q: direct quotation** | Introduction or sufficiently distinctive continuous wording; includes clear whole-line use without formula | Strong text relationship does not make original context exclusively a New Testament event |
| **Q｜直接引用** | 有引介语，或连续措辞足够独特，能合理称为引用；也包括没有公式、却明显把整句诗文说出的例子 | “直接引用”说明文本关系强，不自动证明原诗第一处境只指新约事件 |
| **R: clear reuse** | Recognizable wording, image, argument, adapted or without introduction | Explain changed or expanded function |
| **R｜明确重用** | 新约明显采用该诗的措辞、意象或论证结构，但经过改写、角色转换、缩写或没有正式引介 | 需要同时说明新约怎样改变或扩展原诗的功能 |
| **E: possible echo** | Vocabulary and context suggest connection, possibly shared language/other source/tradition | Reading clue, not sole doctrinal/historical proof |
| **E｜可能回响** | 词语与语境共同使联系值得考察，但仍可能来自共同圣经语言、另一段经文或一般传统 | 只能作为阅读线索，不能单独承担教义或历史证明 |
| **—: none listed this round** | No current correspondence meets threshold | Does not mean no use, thematic, liturgical, or reception connection |
| **—｜本轮暂无列入** | 当前工作版没有达到上述阈值的对应 | 不表示新约从未使用这一篇，也不表示主题、礼仪和接收史完全没有联系 |

Composite and disputed-source labels are not an additional strength level. They flag New Testament wording resembling multiple Old Testament passages, where one exclusive source should not be forced.<br>
附加的“**复合**”或“**来源有争议**”不是第四种强度，而是提醒：同一句新约文字可能同时靠近两段以上旧约经文，不能强行指定唯一来源。

<a id="psalms-index-2-why-reference-tools-count-differently"></a>
### 2. Why Reference Tools Count Differently | 2. 为什么不同工具会给出不同数字

Introductions and continuous wording make quotations relatively identifiable. Allusions/echoes depend on rare words, order, context, available texts, and an interpreter’s threshold. Larry Hurtado’s count from NA28’s appendix gives Psalms 2, 22, 69, 78, 89, 110, 118, and 119 respectively 19/8, 23/8, 17/5, 21/2, 26/0, 21/9, 19/10, and 14/0 uses/quotations. The figures themselves show:<br>
“引用”尚可依引介语和连续措辞较稳定地判断；“暗引／回响”则取决于词汇稀有度、次序、上下文、作者可接触的文本和解释者采用的阈值。Larry Hurtado 按《Nestle-Aland 希腊文新约》第 28 版附录所作的统计，列出诗篇 2、22、69、78、89、110、118、119 分别有 `19/8、23/8、17/5、21/2、26/0、21/9、19/10、14/0` 个“使用／其中引用”；这组数字本身就显示：

- A psalm may have many possible uses but no direct quotation classified by the editors, as with Psalms 89 and 119.
  某篇可能有很多可能使用，却没有一次被编辑者列为直接引用，例如诗篇 89、119；
- Counts result from editorial judgment, not a citation inventory left by ancient authors.
  数字是编辑判断的结果，不是古代作者留下的引用次数清单；
- The Psalm 110 count includes Mark 16:19, whose longer ending has a separate textual-history problem.
  诗篇 110 的数字包含马可福音 16:19，而马可福音较长结尾本身另有文本史问题。

This index prefers fewer graded entries to upgrading every thematic resemblance into fulfillment.<br>
因此，本表宁可少列、分级，也不把所有主题相似都升级为“应验”。

<a id="psalms-index-3-numbering-warning"></a>
### 3. Numbering Warning | 3. 编号警告

All entries use **Masoretic / most Protestant Chinese Bible numbering**. Greek Septuagint divisions merge or split some poems, so numbering is not simply one lower from a particular point onward:<br>
本表一律使用**马所拉本／多数新教中文圣经编号**。希腊《七十士译本》因合并或拆分若干篇，编号不是从某处开始永远简单减一：

| Masoretic number / 马所拉本编号 | Septuagint number / 七十士译本编号 |
| --- | --- |
| 1–8 | 1–8 |
| 9–10 | Combined as 9 |
| 9–10 | 合为 9 |
| 11–113 | 10–112 |
| 114–115 | Combined as 113 |
| 114–115 | 合为 113 |
| 116 | Split as 114–115 |
| 116 | 分为 114–115 |
| 117–146 | 116–145 |
| 147 | Split as 146–147 |
| 147 | 分为 146–147 |
| 148–150 | 148–150 |

For example, Psalm 110 here is 109 in most Septuagint tools, and Psalm 51 is 50. Establish the numbering system before checking Hebrews or Greek-text research.<br>
例如，本表的诗篇 110 在多数七十士译本工具中是诗篇 109；诗篇 51 则是诗篇 50。核对希伯来书或希腊文本研究资料时，先确认对方采用哪套编号。

## Six Cases Requiring Text-Form Comparison | 三、六个必须停下来核对文本形态的案例

| Case / 案例 | Appearance / 表面现象 | Interpretation / 应怎样解释 |
| --- | --- | --- |
| Psalms 14/53 → Romans 3:10–12 | Parallel psalms used in a multi-text catena | Do not assign every phrase uniquely; follow Paul’s universal-sin argument |
| 诗 14／53 → 罗 3:10–12 | 两篇本来就有平行正文，罗马书又把多段诗篇串成连锁引用 | 不应假装每个短语都能唯一反查到一篇；先看保罗整组“普世都在罪下”的论证 |
| Psalm 34:20 / Exodus 12:46 / Numbers 9:12 → John 19:36 | Unbroken bones resemble righteous protection and Passover lamb rules | Possible deliberate combination; Chinese wording alone cannot exclude other sources |
| 诗 34:20／出 12:46／民 9:12 → 约 19:36 | “骨头一根也不折断”同时接近义人蒙保守和逾越节羊羔规定 | 可讨论约翰是否有意叠合两条线，但不能只凭中文相同词语排除其他来源 |
| Psalm 40:6–8 → Hebrews 10:5–10 | Masoretic opened ears versus Greek prepared body | Hebrews argues from available Greek form; neither copying mistake nor ignorable version difference |
| 诗 40:6–8 → 来 10:5–10 | 马所拉本近于“开通耳朵”，希腊文本是“预备身体” | 希伯来书依据可用的希腊经文形态作论证；这不是抄错，也不能忽略版本差异 |
| Psalm 68:18 → Ephesians 4:8 | Victor receives gifts in psalm, gives gifts in letter | Possible distribution of spoils; disclose changed verb |
| 诗 68:18 → 弗 4:8 | 诗篇写得胜者“受礼物”，以弗所书写“赐恩赐” | 解释重点可能是得胜者把战利品分给属下；必须把动词改变公开写出 |
| Psalm 97:7 / Deuteronomy 32:43 → Hebrews 1:6 | Both Greek texts have heavenly worship; continuous wording nearer Deuteronomy | Retain composite background, not one cross-reference hiding dispute |
| 诗 97:7／申 32:43 → 来 1:6 | 两处希腊经文都有天上众者敬拜的语言，但来 1:6 的连续措辞更靠近希腊申命记 | 保留复合背景，避免用一个交叉引用符号掩盖来源争论 |
| Psalms 78:24 / 105:40 / Exodus 16 → John 6:31 | Heavenly bread in narrative and two historical psalms | Whole manna tradition; exact verse source differs from developed storyline |
| 诗 78:24／105:40／出 16 → 约 6:31 | “从天来的粮”既在历史叙事，也在两篇历史诗中重述 | 约翰使用的是整条吗哪传统；“引用哪一节”与“发展哪条故事线”是两个问题 |

<a id="psalms-index-five-steps-for-following-a-psalm-into-the-new-testament"></a>
## Five Steps for Following a Psalm into the New Testament | 四、从诗篇反查新约时的五步法

1. **Read the whole psalm first.** Identify speaker, crisis, turn, and ending; do not turn an isolated line into a prediction code.
   **先读整篇诗。** 至少确认说话者、危机、转折和结尾，避免只把一句拆成预测密码。
2. **Read the New Testament passage.** Ask whether the citation serves identity, suffering, resurrection, ethics, worship, or communal exhortation.
   **再读新约段落。** 问引用在论证中承担身份、受苦、复活、伦理、敬拜还是群体劝勉功能。
3. **Compare text forms.** Check Masoretic Hebrew, Septuagint, and New Testament Greek, resolving numbering first.
   **比较文本形态。** 同时核对马所拉本、七十士译本和新约希腊文；先处理编号差异。
4. **Look for composite sources.** Retain multiple candidates when the wording also resembles Torah, prophets, or another psalm.
   **寻找复合来源。** 若同一句也靠近律法书、先知书或另一篇诗，公开保留多个候选。
5. **Separate historical judgment from theological confession.** Comparison shows how an author uses Scripture. Identifying Jesus as the anointed king is a New Testament/church confession, not an automatic word-frequency result.
   **分开历史判断与神学认信。** 文本比较可以显示作者怎样使用经文；“耶稣就是受膏君王”是新约及教会的神学宣告，不是词频工具自动证明的结论。
