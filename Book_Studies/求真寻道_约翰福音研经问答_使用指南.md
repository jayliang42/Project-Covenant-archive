<a id="orientation"></a>
## English Orientation | 英文简介

This is a Chinese-language workbook for studying John verse by verse. Its public description emphasizes small-group leadership, Greek-word observations, translation comparison, discussion questions, and active participation. This guide does **not** reproduce the 46 copyrighted lessons or invent their individual titles. Instead, it provides a canonical map of John, a method for using the workbook responsibly, and theological guardrails for group discussion.

<a id="central-question"></a>
## The Gospel's Central Question | 约翰福音的总问题

约翰福音反复追问：**耶稣是谁？人如何因信祂得生命？**

全书不是单纯收集神迹或道德教训。叙事不断推动读者面对耶稣的言行、见证、记号、冲突、十字架与复活，并作出回应。约翰福音 20:30–31 是阅读钥匙：记号指向耶稣的身份，信靠指向在祂名里的生命。

```text
道成肉身的启示（1:1–18）
        ↓
记号、见证与初步信心（1:19–4:54）
        ↓
冲突加深：安息日、生命之粮、光与牧者（5–10）
        ↓
拉撒路与进耶路撒冷：生命、死亡与荣耀（11–12）
        ↓
最后晚餐与临别教导：爱、圣灵、住在基督里（13–17）
        ↓
受难、复活与差遣（18–21）
```

<a id="two-threads"></a>
## Two Threads to Trace | 两条贯穿线索

<a id="seven-signs"></a>
### Seven Signs | 七个记号

常见的阅读安排把下列事件称作“七个记号”：迦拿婚宴变水为酒（2:1–11）、医治大臣之子（4:46–54）、医治毕士大池边的人（5:1–18）、喂饱五千人（6:1–15）、水面行走（6:16–21）、医治生来瞎眼的人（9:1–41）、叫拉撒路复活（11:1–44）。这种数法有助于看见叙事结构，但不是唯一的学术划分；重点在于每个记号都引出关于耶稣身份与信心的解释和冲突。

追踪问题：每个记号显出什么？人物如何回应？耶稣有没有把注意力从“神迹本身”转向祂自己的身份、使命或十字架？

<a id="i-am-sayings"></a>
### The “I Am” Sayings | “我是”宣告

可重点标记七个带谓语的“我是”宣告：生命的粮（6:35）、世界的光（8:12）、羊的门（10:7）、好牧人（10:11）、复活和生命（11:25）、道路、真理、生命（14:6）、真葡萄树（15:1）。也要注意约翰福音中无谓语的“我是”表达，如 8:58；这些经文与出埃及记的神名主题如何关联，需要在上下文和整本圣经中仔细处理，不应只靠一个希腊字就下结论。

<a id="how-to-use"></a>
## How to Use the 46 Lessons | 怎样使用这本 46 课教材

<a id="four-steps"></a>
### Four Steps for Each Lesson | 每课四步

1. **先读经文，不先看问题。** 圈出人物、地点、重复词、连接词、对比、引文和叙事转折。
2. **再做教材的问题。** 先让经文回答，再用教材的字义、译本与提问帮助你看见原来忽略的细节。
3. **区分三层答案。** “经文直接说什么”“我据此作了什么解释”“我今天应当如何回应”。三层不能混写。
4. **以基督为中心地应用。** 约翰福音的应用不是把耶稣变成成功、健康或关系技巧的例子，而是信靠祂、住在祂里面、爱祂的子民并被差到世界。

<a id="reading-route"></a>
### Twelve-Week Route (Not a Replacement for the Book's Lesson Order) | 12 周路线（不替代原书课次）

| 周次 | 经文主段 | 使用教材的方法 |
| --- | --- | --- |
| 1 | 1:1–18 | 先完成本书的带领／查经预备内容，再进入序言。 |
| 2 | 1:19–2:25 | 将手中教材中对应见证、呼召与迦拿的课次归在一起。 |
| 3 | 3:1–4:54 | 留意重生、活水、敬拜、使命与信心如何相连。 |
| 4 | 5:1–6:71 | 追踪“生命”“工作”“粮”与人的误解。 |
| 5 | 7:1–8:59 | 追踪节期、活水、光、见证与“我是”。 |
| 6 | 9:1–10:42 | 对比肉眼得看见与属灵看见；查考牧人与羊。 |
| 7 | 11:1–12:50 | 阅读拉撒路、荣耀、死亡与信心的关系。 |
| 8 | 13:1–14:31 | 留意洗脚、爱、背叛、安慰与圣灵应许。 |
| 9 | 15:1–16:33 | 查考住在基督里、结果子、受逼迫与圣灵见证。 |
| 10 | 17:1–26 | 慢读耶稣的代祷，特别观察荣耀、真理、合一与使命。 |

把原书 46 课分配到这些周次时，请以你自己的目录和每课经文范围为准；不要为了凑进度跳过上下文。

<a id="guardrails"></a>
## Exegetical Guardrails for Group Leaders | 带领小组的释经界线

| 好的做法 | 需要避免 |
| --- | --- |
| 先问段落在当时叙事中是什么意思，再问今天如何应用。 | 把任何一句耶稣的话抽离对象、场景与上下文。 |
| 比较译本来发现需要查考的地方。 | 用不同译本的差异制造彼此对立，或以为某一译法自动解决全部问题。 |
| 把希腊文字义当作观察线索，核对用法与语境。 | 从词源或一个字典义直接推出经文唯一含义。 |
| 让所有人参与，同时由经文约束讨论。 | 让分享变成经验竞赛，或以“我觉得”取代文本理由。 |
| 承认约翰福音的犹太语境和书中复杂人物。 | 用“犹太人”这一叙事用语做反犹或群体污名化的结论。 |
| 把神迹、十字架与复活读成约翰对耶稣的见证。 | 把神迹降格为只要有信心就能得到好结果的公式。 |
