## What This Section Stores | 本区保存什么

- Official acquisition links and version metadata.
- Reading-use profiles, including where a translation may help English learners.
- Copyright and permission boundaries for a public repository.

本区不镜像受版权保护的整本圣经文本、应用安装包或专有模块。需要离线版本时，请从版权方指定的渠道个人取得；本仓库的 `Private_Downloads/` 路径已被 Git 忽略，避免误上传。

## How to Use a Translation in This Library | 怎样配合本资料库使用译本

1. Use a translation to read the biblical passage itself.
2. Use the timeline and historical notes to locate the passage in its literary and historical setting.
3. Compare translations only when the wording matters; do not manufacture a theological conclusion from an English preference alone.
4. Respect each translation’s copyright and license terms before copying, sharing, or publishing text.

译本是进入经文的工具，不是取代经文语境、原文研究或教会共同分辨的捷径。
